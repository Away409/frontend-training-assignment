## 使用的语义化标签
- header：页头，包含 h1 和 nav
- nav：页面内部导航
- main：页面主要内容容器
- section：关于我、技能栈、学习路线、留言反馈
- aside：学习提醒
- footer：作者、课程、更新时间
- figure / figcaption：头像及说明
- table / thead / tbody / th / caption：学习路线表
- form / label / input / select / textarea / button：留言表单

## 最满意的一处结构设计
导航链接与各 section 的 id 一一对应，点击即可跳转，
结构层次在开发者工具里展开时非常清晰。

## 遇到的一个问题及解决方法
问题：图片路径写成绝对路径，换电脑后图片不显示。
解决：改为相对路径 ./assets/profile.svg，并把图片放进 assets 目录。
