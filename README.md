## 本地运行

下载或克隆仓库后，用 Edge 或 Chrome 打开相应项目的 `index.html`。
GitHub 文件页展示源码，需下载到本地才能直接运行网页。

也可在仓库根目录运行：

```sh
python -m http.server 8000
```

然后访问 `http://localhost:8000/` 并进入相应目录。Todo 数据保存在当前浏览器的 localStorage 中，使用同一访问地址可在刷新后恢复。
