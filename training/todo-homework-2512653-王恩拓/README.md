## 启动方法

解压后用 Edge 或 Chrome 打开 `index.html`。项目无需安装依赖。如浏览器限制本地文件访问存储，可在项目目录运行 `python -m http.server 8000`，然后打开 `http://localhost:8000/`。使用同一浏览器和同一访问地址可恢复已保存的任务。

## 已完成功能

- 点击“添加”或按回车新增任务，自动去除首尾空格并提示空标题。
- 勾选或取消勾选任务，支持逐项删除。
- 按全部、未完成、已完成筛选，并显示全部任务中的未完成数量。
- 使用 `localStorage` 保存任务，刷新后自动恢复。存储数据损坏时显示空清单。
- 使用 `textContent` 渲染任务标题。
